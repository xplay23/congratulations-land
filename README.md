# Videovitannya

Украиноязычный сайт персональных видеоприветов. Реализация на **Vue 3 + Vite**, Composition API и Single File Components. Все страницы заранее рендерятся через `@vue/server-renderer`; контент и SEO доступны без выполнения JavaScript.

## Запуск

Требуется Node.js 22.12+ или 24+.

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173. Для просмотра собранной версии:

```sh
npm run build
npm start
```

## Проверки

```sh
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

Браузерные проверки покрывают desktop/mobile, гидратацию Vue, выбор подарка на первом экране, закрытие мобильного меню клавишей Escape, форму песни, заказ для двух детей, отсутствие отправки персональных данных, redirects и 404. Для уже установленного Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

## Структура

- `src/App.vue` — страницы сайта и их композиция.
- `src/components/HomePage.vue` — главная с центрированным первым экраном и рождественской сценой.
- `src/components/` — Vue-компоненты, включая пошаговую форму.
- `src/content.mjs` — украинские тексты, каталог, цены и статьи.
- `src/seo.mjs` — метаданные, schema.org, маршруты и sitemap.
- `src/styles.css` — дизайн-токены и адаптивные стили.
- `src/order.css` — базовые стили формы заказа.
- `src/entry-server.js`, `src/entry-client.js` — SSG и гидратация.
- `scripts/build.mjs` — генерация `dist/`.

## Текущая готовность

Временно отключена индексация: `src/features.mjs` → `indexingEnabled: false`. Все HTML получают `noindex, nofollow`, Node-сервер также отдаёт `X-Robots-Tag` для страниц и медиа; sitemap без URL, в robots.txt нет ссылки на него. Обход страниц разрешён, чтобы поисковик мог прочитать noindex ([рекомендация Google](https://developers.google.com/search/docs/crawling-indexing/block-indexing)).

`santaVisible: false` скрывает предложение Деда Мороза/Санты из каталога, цен, формы и прямого URL `/novyj-rik/` (404). По умолчанию выбран Святой Миколай. Для возврата поменяйте нужный флаг на `true`, пересоберите проект и перезапустите Node-сервер. Данные предложения сохранены в исходниках. Предыдущие оценки SEO в Lighthouse относятся к состоянию до временного noindex.

На первом экране установлен пользовательский ролик `pilot_andriiko_ua_720p.mp4`: 49 секунд, автозапуск без звука и повтор. Веб-копии — `hero-andriiko-{480,720}.webm` (VP9) и `.mp4` (H.264, faststart). Аудиодорожки удалены, исходник не изменён. Первый нечёрный кадр сохранён в AVIF/WebP/JPEG. Видео загружается после начального отображения страницы; при reduced motion или экономии трафика — только по кнопке. Есть пауза и остановка вне экрана. Компонент — `src/components/HeroVideo.vue`.

Картинки используют `<picture>` с AVIF → WebP → JPEG, адаптивными размерами и отложенной загрузкой вне первого экрана. `public/robots.txt` копируется в сборку, `sitemap.xml` генерируется из индексируемых маршрутов; оба URL доступны и в dev. Production-сервер отдаёт подготовленные Brotli/Gzip и поддерживает byte ranges для обоих видеоформатов. На стороннем static hosting необходимо отдельно включить выдачу `.br`/`.gz` с корректным `Content-Encoding` и кеширование.

[Отчёт производительности](docs/PERFORMANCE.md): локальный Lighthouse, настройки повторного запуска и оставшиеся ограничения. Команда после сборки: `npm run audit:performance -- current --all`.

Композиция сохраняет основу из `DESIGN.md`: центрированный первый экран и выбор подарка, закреплённая навигация, просторные секции и карточки. По последующему запросу владельца палитра изменена на тёплую рождественскую: кремово-белые поверхности, красные действия и клюквенный подвал. Первый экран и фотографии подарков обновлены под эту палитру. Исходный `DESIGN.md` сохранён; изменения описаны в `docs/design/REFERENCE-IMPLEMENTATION.md`. Rubik Variable поставляется локально через Fontsource с кириллицей; функциональные иконки — Phosphor. Внешние CDN шрифтов не используются.

Таблица стилей подключена непосредственно в `index.html`, а начальный кремовый фон и светлая цветовая схема заданы встроенным CSS для устранения белой вспышки при переходах. SSR/SSG и обычная навигация между страницами сохранены; роутер и анимации переходов не добавлены.

Это первый этап реализации сайта. Форма позволяет выбрать продукт, заполнить данные, добавить фото локально и проверить макет. **Генерация, платежи, отправка писем и кабинет пока не подключены.** Личные данные не уходят на сервер и не сохраняются. Макет последнего шага явно подписан, он не выдаётся за настоящее видео.

Сайт не опубликован. Документы оферты и полной политики ожидают утверждения владельцем и юристом. Сборка предназначена для просмотра первого этапа; для коммерческого запуска нужны интеграции из `docs/IMPLEMENTATION.md`.

Для размещения можно использовать Node-сервер из проекта либо static hosting с содержимым `dist/`. На static hosting нужно отдельно настроить HTTP→HTTPS, www→без www, lowercase/trailing slash и код 404 для `404.html`. Для Node за доверенным HTTPS proxy доступен `TRUST_PROXY=true`; без доверенного proxy этот параметр не включать.
