# Статус реализации

## Источники и границы этапа

Исходное ТЗ от 15.11.2026 сохранено в `specification/website-specification.pdf`; текстовая версия облегчает поиск. Стилевой референс Mercury перенесён из корня в `design/DESIGN.md` без правок.

Текущий этап — Vue-фронтенд, SSG и демонстрация заказа. Это не готовый коммерческий сервис. Начальная реализация без фреймворка заменена Vue 3 по просьбе владельца; параллельной старой реализации нет.

## Реализовано

- Vue 3 SFC, Composition API, Vite; серверный рендер компонентов при dev и предварительная генерация HTML при build.
- Главная, пять действующих по структуре услуг, будущий мультфильм с noindex, цены.
- О сервисе, контакты, состояния юридических документов до утверждения.
- Блог, пять хабов, три оригинальные сезонные статьи. Хабы с менее чем тремя статьями закрыты от индексации.
- Состояния кабинета, оплаты и результата без обещания работающей интеграции.
- Настоящая HTTP 404; lowercase и trailing slash 301; параметризованные страницы noindex с canonical без параметров.
- Самоссылочные canonical, lang=uk, OG, Twitter Card, JSON-LD Organization/WebSite/Service/AggregateOffer/FAQPage/ItemList/Article/BreadcrumbList; sitemap с lastmod и robots.txt.
- По одной H1 на каждой странице, уникальные метаданные индексируемых страниц с проверкой длины. Нет фиктивных отзывов и рейтингов.
- Адаптивная навигация, клавиатурный фокус, skip-link, нативные FAQ, учёт reduced motion.
- Главная сохраняет композицию референса Mercury: центрированный заголовок с выбором подарка, закреплённая шапка и просторные секции. По последующему запросу владельца применена тёплая красно-белая рождественская палитра с кремовыми поверхностями, новой интерьерной сценой и предметными фотографиями. Исходный `DESIGN.md` сохранён; изменения описаны в `design/REFERENCE-IMPLEMENTATION.md`.
- Локальный Rubik Variable с кириллицей и функциональные иконки Phosphor. Главная выделена в `src/components/HomePage.vue`, базовые стили формы — в `src/order.css`.
- Для устранения белой вспышки при навигации таблица стилей подключена непосредственно в `index.html`, начальные фон и светлая цветовая схема заданы встроенным CSS; импорт шрифта стоит первым в `src/styles.css`. Сохранены SSR/SSG и обычные переходы между документами без роутера и анимаций страниц.
- Баннер согласия с сохранением выбора. Аналитика и рекламные пиксели не загружаются.
- Форма: предвыбор продукта, герой, один/два ребёнка, варианты фото/песня/пакет, имена и подсказки кличного відмінка, возраст, увлечения, достижения, пожелание, локальные фото с лимитом 1–3 и 10 МБ, согласия, жанр, настроение, три факта, история до 500 символов, email, необязательный контакт, проверка данных заказа.
- Цены из одного источника `src/content.mjs`; расчёт суммы в Vue; данные формы сохраняются при возврате между шагами, но не после обновления.
- Атмосферные AI-изображения без лиц клиентов, локальные WebP, индивидуальные OG для коммерческих страниц.

## Следующий этап: backend и интеграции

1. Выбрать провайдеров генерации видео и песен. Уточнить права на песни и изображения, подготовить оригинальные demo-video/audio и согласовать образы героев.
2. Реализовать API заказов, БД, приватное object storage, проверку файлов по сигнатуре, безопасную обработку HEIC, модерацию текста и согласий. Текущая проверка фото клиентская и не заменяет серверную.
3. Очередь генерации с адаптерами, двумя повторами, учётом стоимости и ручным разбором ошибок. Лимиты превью 3/email и 5/IP в сутки — только на сервере. Защитить от обхода и параллельных запросов.
4. Настоящее превью: фото 3–4 с, песня 20–30 с, сцена героя с именем. Водяные знаки. Неоплаченные превью и исходники удалять через 7 дней.
5. На шаге перед оплатой показывать сводку заказа. Подписи webhook, проверка суммы/валюты/order ID, идемпотентность событий. Полная генерация только по подтверждённому платежу; согласованный сценарий возврата при сбое.
6. Email: подтверждение, готовность, напоминания через 2 часа/1 день. Вход по одноразовой ссылке или email-коду, защищённые сессии.
7. Кабинет: статусы, скачивание, повтор заказа, удаление данных. `/v/{token}/` с криптографически случайным токеном, noindex/nofollow, Referrer-Policy: no-referrer. Готовый файл хранить минимум 12 месяцев, исходники удалять через 30 дней после доставки.
8. Админка с авторизацией и журналом действий: заказы, стоимость, модерация, повтор генерации, возвраты, цены, промокоды, SEO-поля. Перенести цены из файла в БД/CMS без дублирования.
9. Утвердить реквизиты, канал поддержки, оферту и полную политику с конкретными провайдерами. До этого платные заказы заблокированы.
10. Подключить GA4 и consent-aware Meta/TikTok; события form_start, form_step, preview_ready, begin_checkout, purchase, video_play. Демо-макет не должен посылать preview_ready или purchase.
11. Подключить домен, HTTPS, redirects, Search Console; проверить Rich Results и URL Inspection; измерить LCP/CLS/INP на реальных мобильных пользователях. Текущая сборка не подтверждает целевые CWV.

## Отклонения от полного ТЗ на текущем этапе

- Нет настоящего demo-плеера: на страницах размещены концепты атмосферы с явной подписью. Поэтому VideoObject/AudioObject не публикуются — у них пока нет реального медиафайла.
- Тестовая оплата через plata by mono сохраняет технические данные счёта и проверяет статус через API банка. Персональные поля и фото остаются в памяти браузера. Для коммерческого запуска ещё нужны генерация, доставка, кабинет и подключение боевого эквайринга.
- Результаты по срокам генерации не выдумываются: числа появятся после теста провайдеров.
- Пустые хабы имеют короткое состояние ожидания, а не фиктивные статьи; полный вводный текст и пагинация появятся с наполнением.
- Для страницы дня рождения доступны украинская и русская версии с взаимными hreflang. В форме выбор продукта и повода хранится отдельно.
- Rubik Variable поставляется локально через Fontsource, без внешних CDN. Он заменяет коммерческие Arcadia/Söhne из референса, которые не поставляются без лицензий.
- Оферта и политика не выданы за утверждённые юридические документы.
- Сборка подготовлена для локального ревью; коммерческий запуск требует перечисленных выше интеграций.
