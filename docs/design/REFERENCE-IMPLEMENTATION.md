# Композиция референса и рождественская палитра

Исходный [DESIGN.md](DESIGN.md) сохранён без изменений. Главная использует его композицию с содержанием из ТЗ видеопривитаний. Последующий запрос владельца на тёплый красно-белый рождественский стиль заменяет тёмную палитру Mercury; эта корректировка описана здесь отдельно от исходного референса.

- Первый экран: тестовое видео владельца со Святым Николаем на всю ширину, без аудиодорожки, с повтором и кнопкой паузы. Белый заголовок смещён ниже лица героя и читается на тёплом затемнении. При уменьшенном движении показывается статичный кадр; видео останавливается вне экрана. Ранее созданный фон рождественской комнаты сохранён в ассетах. Выбор подарка передаётся в форму заказа через параметр `product`.
- Шапка: геометрический знак, центральная навигация и действия справа; закреплённая навигация поверх сцены с фоном при прокрутке. Мобильное меню закрывается клавишей Escape.
- Типографика: локальный Rubik Variable с кириллицей, основной вес 400, заголовки 480. Это доступная замена коммерческим Arcadia/Söhne; оригинальные файлы этих шрифтов в проект не добавлены.
- Цвета: фон `#fff8f0`, карточки `#fffdf9`, элементы управления `#f3e5d8`, текст `#4b2424`, приглушённый текст `#785b53`, красный акцент `#b32c36`, его состояние наведения `#94212b`, клюквенный фон акцентной полосы и подвала `#88232c`.
- Геометрия: ширина контента до 1200 px, основные интервалы секций 72 px, радиус карточек 12 px, кнопок 32 px. Адаптивные правила уменьшают отступы и перестраивают сетки.
- Функциональные иконки импортируются из Phosphor по именам. Декоративные рукописные подписи, крупная нумерация и цитата убраны.
- Ниже первого экрана: пять карточек подарков в сетке 2+3, текст с изображением о предварительном просмотре, этапы заказа, приватность, FAQ и статьи в компактных строках.

Главная находится в `src/components/HomePage.vue`. Общая визуальная система — в `src/styles.css`; базовые стили формы вынесены в `src/order.css`. Локальный Rubik из Fontsource импортируется первым в `src/styles.css`.

Изображение первого экрана `public/assets/christmas-hero.webp` и пять предметных фотографий `christmas-gifts.webp`, `christmas-letter.webp`, `christmas-birthday.webp`, `christmas-photo.webp`, `christmas-song.webp` созданы встроенным ImageGen. Обложки OG обновлены в тёплой палитре. Промпты и размеры записаны в [ASSETS.md](ASSETS.md). Альпийское и тёмные зимние изображения относятся к предыдущей версии оформления.

Для устранения белой вспышки при переходах `index.html` подключает таблицу стилей обычным `<link rel="stylesheet">`, а встроенный CSS задаёт исходный кремовый фон и `color-scheme: light` до загрузки остальных стилей. Сохранена обычная навигация SSR/SSG между документами: роутер и анимации переходов не добавлялись.

Редизайн не меняет границы текущего этапа: цены и тексты берутся из `src/content.mjs`, форма остаётся демонстрационной. Генерация, оплата, письма, авторизация и сохранение заказов требуют backend-интеграций, перечисленных в [статусе реализации](../IMPLEMENTATION.md).
